# Commodore 64 BASIC 2.0 Programs

This repository contains simple programs written in Commodore 64 BASIC 2.0.

## Programs

### blackjack.bas

A simple Blackjack card game against the computer. The program uses a shuffled 52-card deck and supports hitting and standing. Aces are automatically counted as 1 or 11 when appropriate, and the dealer draws cards until reaching at least 17.

### bouncing_ball_physics.bas

A physics demonstration with multiple bouncing balls. The balls move around the screen with individual velocities and are affected by gravity. They bounce from the walls and floor while gradually losing energy after each collision.

### breakout.bas

A simple Breakout-style game. Use the Z and M keys to move the paddle left and right, bounce the ball against the paddle, and destroy the bricks at the top of the screen. The score increases as bricks are destroyed.

### dice_roller.bas

A dice rolling program that allows you to roll up to 21 dice, each with a customizable number of sides (4-100, even numbers only). The program prompts for the number of dice and the number of sides for each die, then displays the result of each roll.

### disco_screen.bas

A visual effect program that makes the screen flash in random colors, i.e. disco lights.

### fibonacci.bas

Generates and displays the first 20 Fibonacci numbers (1, 1, 2, 3, 5, 8, ...) with a delay between each number.

### hakopirtti_fishing.bas

Simple fishing game. A and D to move the boat sideways, W and S to move the hook vertically.

### matrix_calculator.bas

Matrix calculator that allows the user to input two matrices and perform addition, subtraction, or multiplication. It displays both input matrices and the resulting matrix on the screen.

### matrix_characters.bas

A visual effect program that creates green appearing characters on screen, similar to the Matrix movie effect. It sets up a black background with green text and continuously displays random characters at random screen positions.

### maze_generator.bas

A random maze generator that creates a new maze each time it is run. The program uses a depth-first maze generation algorithm and displays the generated maze using Commodore 64 characters.

### memory_worm.bas

A program that continuously writes random values to random memory locations, creating a "memory worm" effect that corrupts memory addresses across the system.

### number_guessing.bas

A simple number guessing game. The computer picks a random number between 1 and 10, and the player tries to guess it. The program provides feedback and allows multiple attempts until the correct number is guessed.

### pattern_generator.bas

A visual pattern generator that fills the screen with animated patterns by iterating through character codes and displaying random variations of those characters across the screen.

### salon_joki_boatrace.bas

A boat racing game with multiple stages. Navigate through obstacles on the river using Z and M keys to move left and right. The game has 10 stages with increasing difficulty, and your score increases with each stage completed.

### sid_piano.bas

A simple piano that uses the Commodore 64 SID sound chip to play musical notes. The A, S, D, F, G, H, J, and K keys play notes from C to C, and X exits the program.

### sierpinsky.bas

Generates a Sierpinsky triangle fractal pattern on the screen using bitwise AND operations. The pattern is displayed using character 160 and fills the entire screen with the fractal structure.
